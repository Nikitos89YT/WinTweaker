# WinTweaker

WinTweaker — утилита на русском языке для настройки и восстановления Windows. В одном окне можно проверить системные ограничения, разобраться с автозагрузкой, настроить DNS и вывести показатели нагрузки поверх игры.

## Быстрый старт

1. Скачайте архив для Windows x64 из [Releases](https://github.com/Nikitos89YT/WinTweaker/releases).
2. Установите **.NET Desktop Runtime 10 (x64)**, если его ещё нет. [Страница загрузки Microsoft](https://dotnet.microsoft.com/download/dotnet/10.0)
3. Распакуйте архив целиком и запустите **WinTweaker.exe**. Для изменения системных параметров Windows может запросить права администратора.

## Что умеет WinTweaker

| Раздел | Возможности |
| --- | --- |
| Главная | Сведения о компьютере и оверлей Live Monitor. Можно скрывать отдельные показатели CPU, GPU, памяти и сети, включать графики и измерять FPS выбранной игры. |
| Tweaks | Игровой режим, параметры экрана и управление сетью. Выберите адаптер, чтобы увидеть его DNS, применить пресет или вернуть автоматическую настройку. |
| Восстановление | Работа с точками восстановления Windows и резервными копиями настроек приложения. |
| Unlocker | Проверка ограничений для Диспетчера задач, CMD, PowerShell, окна «Выполнить», панели управления с «Параметрами» и редактора реестра. Можно восстановить отдельный инструмент или запустить общую проверку. |
| Автозагрузка | Просмотр источника, команды и состояния записи. Для поддерживаемых записей доступно включение и отключение. |
| Инструменты | Проверка системных файлов и диска, очистка временных файлов, просмотр драйверов и экспорт пакетов драйверов. |

Для отображения памяти в виде **12,2 ГБ / 16 ГБ** откройте шестерёнку в Live Monitor и включите «Память в ГБ (занято / всего)». В этом же меню отдельно настраиваются приём и передача данных.

## Сборка из исходников

В Windows с установленным .NET SDK 10 выполните из корня репозитория:

```powershell
dotnet publish WinTweaker/WinTweaker.csproj -c Release -r win-x64 --self-contained false -o publish
```

Приложение появится в папке `publish`. Для измерения FPS в комплект входит PresentMon. Его лицензия и уведомления о сторонних компонентах находятся в `ThirdParty/PresentMon` рядом с исполняемым файлом.
